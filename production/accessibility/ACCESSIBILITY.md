# Aura Accessibility (a11y) & WCAG Compliance

## Compliance Level: WCAG 2.1 AA / AAA Recommendations
- **Screen Reader Announcer**: Live polite/assertive region managed by `a11y.announce()`.
- **Keyboard Navigation**: Focus trapping in modal drawers, full tab ring support.
- **Color Contrast**: All text elements meet or exceed 4.5:1 WCAG contrast ratio against dark slate backgrounds.
- **Reduced Motion**: Frame animations respect system `prefers-reduced-motion` settings.
