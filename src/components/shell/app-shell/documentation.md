# AppShell Component

Master orchestration layout container for Aura Desktop Shell containing Sidebar, Top Navigation, Workspace, Content Container, Dock, Footer, Command Palette modal, and global hotkeys.

## Usage
```tsx
import { AppShell } from '@/components/shell/app-shell';

<AppShell title="Aura OS Desktop">
  <YourPageContent />
</AppShell>
```
